01

Telegram account

The server logs in as your Telegram user, so it can join chats and download their videos. Get an API ID and API hash at my.telegram.org, under API development tools.

This account has two-step verification. Enter its password.

02

Download a chat

Paste a channel or group link. The server joins it, downloads every video in the order it was posted, and files them as a new archive numbered #1, #2 and so on. Only download chats you have the right to share.

Connect a Telegram account first.
