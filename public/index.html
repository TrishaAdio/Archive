Private by design

  • Locked to one network The same key from a different IP address is refused, even when it is correct.
  • Your key is never stored Only a SHA-256 hash is kept, so a database leak cannot reveal a working key.
  • Links expire in minutes Every playback link is signed to your session and IP, and stops working within about two minutes.
  • No third-party tracking Nothing here loads from another company's servers, so no one else sees what you watch.
